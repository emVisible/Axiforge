## 关于 AXS

AXS（Axiforge eXperience Script）是 Axiforge 的叙事文本语言。在剧本模式中，**AXS 源文本是真相源**：保存时会解析为桥段（Beat）、分支与演出指令，并同步到剪辑台与 Flow 结构图。

## 获取帮助

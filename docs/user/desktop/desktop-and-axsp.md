# 桌面版与工程包

Axiforge 桌面版是一个**离线优先**的创作应用：断网也能写完一部作品，素材和工程都存在你自己的电脑上。

## 你的数据在哪里

| 内容 | 位置 |
|---|---|
| 工程、角色、素材索引 | 应用本地数据库（SQLite） |
| 立绘 / 背景 / 音频等素材文件 | `~/Documents/Axiforge/assets/` |
| 首次启动导入的官方示范作 | 随应用打包，不需要联网 |

素材文件名是它内容的 SHA-256 摘要。这意味着同一张图重复导入只会存一份，也让工程包在别的电脑上打开时能认得同一个文件。

## 导入素材

在角色详情页的「立绘」分区，或场景资产页，点图片框 → 选择本机文件即可。桌面版不经过任何服务器：文件被复制进你的素材目录，剧本里记录的是相对引用。

## 把作品交给别人：`.axsp` 工程包

一个 `.axsp` 文件包含**一个作品需要的全部东西**：

- 剧本结构与演出指令（剪辑台、剧本、结构三轨的数据）
- 这部作品用到的**角色档案**（六层模型、立绘差分组）
- 这些角色与场景引用到的**素材文件本体**

导出：剧本列表页或编辑器工具栏的「导出」。
导入：剧本列表页的「导入 .axsp」。导入会新建一份工程，并且**新建角色档案**——不会覆盖你电脑上已有的同名角色，归属记在你名下。

旧版（v1）纯文本工程包仍然可以打开，只是里面不含素材和角色。

## 第一次打开会看到什么

空库首次启动会自动导入三部官方示范作（序章·交汇 / 缘起·选择 / 再会·记忆），可以直接试玩。这个动作**只做一次**：你把它们删掉后不会再次出现，因为那是你的库，不是我们的演示台。

## 让草稿由你自己的模型来写

桌面版**不连我们的服务器**，所以想用模型写演绎草稿，你得指一个自己机器上的端点：

编辑器右上角的「AI · 规则引擎」徽标就是入口，点开填三项——协议（Ollama 或 OpenAI 兼容）、端点、模型名。保存后徽标会变成你选的协议名。**不配置也能用**：内置规则引擎会自己把散文切成台词与舞台指令，断网、没装模型都不影响写完整部作品。

配置只存在你这台电脑上，且**不会被打进 `.axsp` 工程包**——那是你的环境，不是作品内容。

### Ollama 需要设一个环境变量

浏览器内核默认只允许同源请求，`tauri://` 这个来源不在 Ollama 的放行名单里。不设的话症状是"测试一次"报连不上，而 Ollama 明明在跑。解法：

```bash
OLLAMA_ORIGINS="tauri://localhost http://localhost:5174" ollama serve
```

（图省事也可以设成 `OLLAMA_ORIGINS="*"`，代价是本机任意网页都能调你的模型。）

Xinference / vLLM / DeepSeek 这类 OpenAI 兼容服务同理：端点填到 `/v1` 为止，模型名用服务侧列出的那个。

「测试一次」是**真发一次生成**，不是轻量探活——只有走同一条链路，才不会出现"测试说通了、草稿还是失败"。它会占一次推理时间。

## 桌面版目前没有的功能

以下能力依赖协作服务（账号、发布、在线内容），桌面版离线时**入口直接不显示**，而不是点进去报错：

- 发现页与在线作品浏览、全局搜索
- 创作概览数据面板
- 角色版本历史、关系图、Fork
- 剧本的标签 / 机制 / 题材筛选（这些元数据目前只存在服务端）
- 把道具挂进某一拍（道具引用还没有本地存储，见下）

## 已知限制

- **道具引用还没有本地存储**：道具/场景资产页本身在桌面可用（建、改、删、导入舞台库都走本地库），但"把某个道具挂到某一拍"仍需要后端。
- **应用未签名**：目前只产出本地可运行的 `.app` / `.dmg`，没有做 macOS 公证与自动更新。首次打开可能需要在 Finder 里右键 → 打开。

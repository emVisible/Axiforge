## v2.5 已交付：审核判断层（运营视角）

机器结论出现在两个地方，都不是新闸门：

- **审核工作台右侧**「自动判断」条：动作 + 依据（`via` 展开成中文）+ 命中条款 +
  「有执行资格 / 未校准」标记。带虚线框的那枚是**模型建议**（单选"最主要一条"），
  只递到人眼前，不参与任何执行。
- **自动判断队列页**：同一份结论按案件列出来，默认「先看可疑」——按命中条款严重度、
  再看置信度排序。排序不是结论，它只决定谁先看。

两页都能翻页，底部显示「第 x–y 条 · 共 N 条」。这个数字很要紧：此前 `limit` 就是硬上限，
举报列表只显示前 50 条而 pending 有 197 条——看不见的举报不是"排在后面"，是没有入口。

队列页底部有一块**阈值假设**（只读）：填两条假定的线，面板回给你"这 N 条已处置过的案件里
会有几条被自动执行、其中几条与当时的人工结论相反"。它不改策略、不写库，
每一行还会显示**该类型真实生效**的那条线（评论/素材收紧到 0.95/0.97，
所以填 0.75 不等于对评论按 0.75 判）。读数分三种：有误放（红）、会自动执行但缺人工对照（黄）、
与人工一致或什么都不执行（绿）。
读数条同时写明这份证据的**基数**：「扫描 979 条案件，可回放 6 条」——默认窗口已覆盖全库，
真被截断时会追加「全库 N 条，这里只取最新 M 条」，因为"只影响 3 条"和
"在我看得见的这些里影响 3 条"是两个不同的数。注意**可回放**那一项通常远小于扫描数：
只有走过模型那一层的案件才带着可重放的类型化答案，词表判的那些没有向量。

可以点的动作：

| 动作 | 含义 |
|------|------|
| 让模型重判 | 取**全文**（作品 = 简介 + 旁白台词；评论 = 完整正文）现在判一次。内容与策略版本都没变时命中指纹缓存：结论不动，只多一行判断记录，提示语会区分这两种结果。**模型没答话时不覆盖旧结论**：sidecar 死了就点重判，案件保持上一次模型给的条款与置信度，依据里多一行「laya:sidecar 未答话：…」——降级的那次判定没有资格把风险信号抹掉 |
| 确认处置 / 回退 | 人的判断落库并写入审计日志；终态可以回退成待处理（误判要有回去的路） |
| 驳回举报 / 下架内容 | 下架会记违规并累计 strike；重判不会替你做这两步里的任何一步 |

自动化开关的现状：默认 `MODERATION_ENABLED=false`，链里只有词表且它没有执行资格；
打开 Laya 后模型有执行资格，但放行/驳回线（0.90 / 0.95）是扫阈值扫出来的，
未标定的题只要有一题没覆盖就一律转人工。判据口径与实测数字都在
[ADR-028](./ADR/028-moderation-decision-layer-in-admin.md)。

打开 Laya 不再是作者的代价：评论、角色公开、作品保存的判定都挪到了后台
（真机改一次正文的保存耗时 447–980ms → 14–33ms），案件通常在 1–2 秒内出现在队列里。
举报是唯一保持同步的入口——运营打开一条举报时屏上就该有结论，那一次等待是买这笔信息的钱。
也因此队列是**最终一致**的：刚保存的内容短暂地"还没被机器看过"是正常状态，不是丢单。

界面上出现的每一个条款名、规则名、结论名、问题名都来自 `GET /admin/moderation/vocabulary`——
后端在定义它们的那几个模块旁边各放了一份短名，导入期断言与取值域逐项相等。
所以加一条新条款不需要改前端；反过来说，如果哪天你在队列里看到 `spam_promotion`
这样的内部 id，那是词汇表接口出问题了，不是文案没来得及改。

队列页头部常驻四枚状态条，用来回答"为什么没有东西被自动处置"：引擎在线与是否有执行资格、
**温度表覆盖面**、当前策略的通过线/驳回线、**队列结论的版本新鲜度**。覆盖面那一枚分三种读法：
缺哪几题（黄）、取不到标定状态（红）、题数齐但**拟合触到搜索网格上限**（黄）。
最后一种最容易被读成"标定完成了"——它的意思其实是"这几题的置信度还虚高，只是压不到线下"，
所以它不复用全绿的外观。题目名字来自词汇表，界面不会出现 `pii_real_person` 这种内部字段名。

第四枚说的是一件很容易忽略的事：**判定只在内容被保存那一刻发生**，题集或词表改版**不会自己回头
重算**。所以「待处置 994 条」并不等于「994 条同等新鲜的证据」——真机读数就是
「版本已推进但结论没重算：264 条是 questions-3 之前的题集判的、111 条挂着旧词表版本」，
意思是这些行要让结论变新鲜，只能逐条点「让模型重判」（或等批量重判那条路定下来）。

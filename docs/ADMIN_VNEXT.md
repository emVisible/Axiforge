# Admin 管理中台 vNext 规划

> **文档性质**：v2.2+ 管理中台迭代基准，接替 `REFACTOR_V2.md` Phase A 首版。  
> **最后更新**：2026-07-09

## 北极星

**审核员打开一条举报，无需离开页面即可看到被审内容、作者风险、历史违规，并完成下架/驳回。**

与主站 `apps/web` 共用 `@axiforge/ui` + design tokens + 主题系统，避免「两个产品」的割裂感。

---

## v2.2 已交付（本轮）

| 项 | 说明 |
|----|------|
| 审核内容预览 | `GET /admin/reports` 附带 `target_preview`（标题/摘要/封面/作者/strike/违规次数） |
| 审核工作台 | 左队列 + 右预览面板；待处理 / 已下架 / 已驳回 Tab |

| 主站跳转 | 预览区「在主站打开」+ 侧栏主站链接（`VITE_WEB_ORIGIN`） |
| 角色下架 | `PATCH /admin/characters/{id}/status` + 内容管理页操作 |

## v2.3 已交付（本轮）

### A. 审核体验深化

- [x] **同屏关联**：作品/角色/评论举报展示最近 5 条关联评论，可一键下架
- [x] **作者画像卡**：strike、作品/角色数、违规次数，直达用户管理与违规记录
- [x] **键盘快捷键**：`j/k` 切换队列，`d` 驳回，`t` 下架
- [x] **批量处理**：同目标举报自动一并处理（`resolve_siblings`），队列 ×N 徽章 + 多理由展示

### C. 治理闭环

- [x] 内容管理下架作品路径补齐 violation + strike

## v2.4 已交付（本轮完善）
